# Food Store - TypeScript (Evaluación 1 - Programación III)

##Alumno: Rodrigo Aguero
Aplicación web frontend desarrollada como parte de la Tecnicatura Universitaria en Programación (UTN). Consiste en un catálogo de productos dinámico con un sistema de carrito de compras persistente, buscador y filtros por categoría.

## 🚀 Funcionalidades Principales

* **Catálogo Dinámico:** Visualización de productos organizados por tarjetas con imagen, descripción, precio y botón de compra.
* **Búsqueda y Filtros:** Buscador por nombre en tiempo real y filtrado de productos mediante un menú lateral de categorías
* **Carrito de Compras:** Funcionalidad para agregar productos, actualizar cantidades (acumulando ítems repetidos) y calcular el monto total
.
## 🛠️ Tecnologías Utilizadas

* **HTML5** y **CSS3** (Diseño adaptable)
* **JavaScript** / **TypeScript** (Tipado estricto mediante interfaces: `IProduct`, `ICartItem`, `ICategoria`)
* **Vite** como empaquetador y servidor de desarrollo
