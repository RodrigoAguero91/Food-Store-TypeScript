# Food Store - Frontend TypeScript + Vite

Trabajo Práctico Integrador - Programación III (UTN).

## Descripción
Aplicación web frontend de **Food Store** desarrollada en TypeScript y Vite con autenticación por roles (`admin` / `client`), catálogo filtrable por categoría y búsqueda, carrito con control de stock, confirmación de pedidos, historial de pedidos y panel de administración.
